# Ojas Birthday Website 🎂

A five-page birthday website with a photo, birthday letter, wishes, and an interactive cake.

## Run it on your computer
1. Extract the ZIP.
2. Open `index.html` in Chrome or Edge.
3. The microphone candle feature works on `localhost` or an HTTPS website. The button works without microphone permission.

## Publish free with GitHub Pages
1. Sign in at https://github.com/ and create a **New repository**.
2. Name it `ojas-birthday` and set it to **Public**.
3. Choose **Add file → Upload files**.
4. Upload all five HTML files, `style.css`, `script.js`, `README.md`, and the `assets` folder (containing `ojas.jpg`). Upload the contents of this project, not the ZIP file.
5. Click **Commit changes**.
6. Open the repository's **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch **main** and folder **/(root)**, then click **Save**.
9. Wait a minute or two. GitHub will show your website URL, usually:
   `https://YOUR-USERNAME.github.io/ojas-birthday/`

If you update any file later, upload the replacement and commit the changes. GitHub Pages will publish the update automatically.

## Personalise it
- Edit the birthday letter in `letter.html`.
- Edit the wishes in `wishes.html`.
- Replace `assets/ojas.jpg` with another photo, keeping the same filename.
- Edit colours and layout in `style.css`.
